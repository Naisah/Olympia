# Barangay Olympia - HCI Project

## Setup Instructions for Groupmates

To run this project on a new device, you don't need to manually import a raw database file. The system is built with Laravel's automated database migrations and seeders, which will generate the complete, ready-to-use database for you in just one command!

### Prerequisites
1. **Laragon / XAMPP** (Make sure Apache/Nginx and MySQL are running)
2. **Node.js** (Installed)
3. **Python 3.10+** (Installed for the AI facial recognition)

---

### Step 1: Database Setup (Backend)
1. Open your Laragon/XAMPP database manager (e.g., HeidiSQL or phpMyAdmin).
2. Create a new empty database named exactly: `barangay_olympia_db_v2`
3. Open a terminal inside the `backend/` folder and run:
   ```bash
   composer install
   copy .env.example .env
   php artisan key:generate
   ```
4. Finally, build and populate the entire database automatically:
   ```bash
   php artisan migrate:fresh --seed
   ```
   *(This command will create all the tables and instantly fill them with our default News, Gallery, Residents, and Admin accounts!)*

5. Start the backend server:
   ```bash
   php artisan serve
   ```

---

### Step 2: AI Facial Recognition (Python API)
1. Open a new terminal inside the `ml_service/` folder.
2. Install the required Python AI packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the AI Server:
   ```bash
   uvicorn main:app --reload --port 8001
   ```

---

### Step 3: Website Interface (Frontend)
1. Open a final terminal inside the `frontend/` folder.
2. Install the Node packages:
   ```bash
   npm install
   ```
3. Start the website:
   ```bash
   npm run dev
   ```

---
